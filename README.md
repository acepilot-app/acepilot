# AcePilot for Claude Code

A bolt-on autonomous execution system for Claude Code. 6 specialist agents that turn Claude Code into a full product team — designer, security engineer, architect, strategist, reviewer, researcher. Scan to PR.

**Not a fork. Not a wrapper. Config files.** 12 files that install into Claude Code's native config structure. Without activation, Claude Code runs 100% stock.

## Quickstart

```bash
git clone https://github.com/acepilot-app/acepilot.git
cd acepilot
./acepilot-8.0/install.sh
```

Then open Claude Code and type `/acepilot`.

## Modes

| Mode                 | What it does                                 |
| -------------------- | -------------------------------------------- |
| `/acepilot plan`     | Show tasks with scope and gate. Stop.        |
| `/acepilot go`       | Execute tasks, check in on issues.           |
| `/acepilot continue` | Keep going — remaining tasks or find new.    |
| `/acepilot auto`     | Self-fixing autonomous execution. Pro.       |
| `/acepilot ship`     | Auto + specialist review + PR. Pro.          |
| `/acepilot god`      | Smart dispatch specialists. Zero stops. Pro. |
