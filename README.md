# AcePilot for Claude Code

A self-evolving autonomous engineer with a built-in growth engine. 6 specialist agents. 14 persistent state files. Playbooks that replay proven workflows. A growth engine that auto-generates user acquisition infrastructure for every product you build.

**Not a fork. Not a wrapper. Config files.** 12 files that install into Claude Code's native config structure. Without activation, Claude Code runs 100% stock. With it, Claude Code ships products and grows users.

## Quickstart

```bash
git clone https://github.com/acepilot-app/acepilot.git
cd acepilot
./acepilot-11.0/install.sh
```

Then open Claude Code and type `/acepilot`.

## Modes

| Mode                 | What it does                                 |
| -------------------- | -------------------------------------------- |
| `/acepilot plan`     | Show tasks with scope and gate. Stop.        |
| `/acepilot go`       | Execute tasks, check in on issues.           |
| `/acepilot continue` | Keep going — remaining tasks or find new.    |
| `/acepilot auto`     | Self-fixing autonomous execution. Pro.       |
| `/acepilot ship`     | Auto + specialist review + PR. Pro.          |
| `/acepilot god`      | Smart dispatch specialists. Zero stops. Pro. |

## What's new in v11.0

- **Growth Engine** — auto-generates SEO, comparison pages, viral loops, blog scaffold, email capture, analytics for every product build
- **Launch Sequence** (`god --launch`) — generates Show HN, Twitter threads, Reddit posts, pre-launch checklist
- **Content Engine** — 5 blog post templates with content calendar
- **Conversion Framework** — sticky CTAs, exit-intent capture, pricing optimization
- **GROWTH.md** — 14th state file for acquisition metrics

Plus everything from v10 (playbooks, self-calibration, session chains, deploy pipeline).
