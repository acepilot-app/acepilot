Two families. Mono for identity and code. Sans for everything readable.

--text-xl Section headings 22px / 700
--text-2xl Page titles 28px / 700

Border Radius

Three values. Small for tight UI, medium for most components, large for cards.

--radius-sm 4px — tags, inline code
--radius-md 8px — buttons, inputs, badges
--radius-lg 12px — cards, modals, panels
pill 100px — status badges

Shadows

Used to establish depth on dark backgrounds. Keep it subtle — this isn't light mode.

--shadow-sm 0 1px 3px rgba(0,0,0,.4)
Subtle lift, hover states
--shadow-md 0 4px 16px rgba(0,0,0,.5)
Card hover, dropdowns
--shadow-lg 0 12px 40px rgba(0,0,0,.6)
Modals, floating panels

Motion

Fast, intentional. No animation that doesn't inform the user.

Token Value Use
--duration-fast 0.15s ease Color/border transitions, hover states
--duration-base 0.2s ease Transform transitions (cards lifting)
--duration-reveal 0.5s ease Scroll reveal opacity + translateY
--duration-typewriter 40–120ms/char Terminal typewriter (variable speed = human)
--cursor-blink 0.9s step-end infinite Terminal cursor blink
ℹ
Always respect prefers-reduced-motion. Wrap animations in @media (prefers-reduced-motion: no-preference).

Usage Rules

What to always do. What to never do.

Do
  • One primary CTA per screen
  • All text on dark bg: use #a1a1a6 minimum for muted
  • Label every input — no placeholder-only fields
  • Use mono font for all metrics, counts, code
  • Respect prefers-reduced-motion
  • Keep 4px spacing base — all values ÷ 4 = integer
Don't
  • Use #8e8e93 — fails WCAG AA (3.3:1)
  • Add icon mark next to "AcePilot" wordmark — double A
  • Use playing card visuals — reads gambling brand
  • Use light backgrounds — dark theme only
  • Use more than 2 typefaces on one page
  • Skip aria-hidden on decorative SVGs
